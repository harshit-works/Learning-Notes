# Wireshark

Wireshark is a network protocol analyzer.

It captures and displays network packets in real time.

---

## Uses

- Troubleshooting network problems
- Packet analysis
- Cybersecurity investigations
- Learning networking

---

# Nmap

Network Mapper

Nmap is a network scanning tool.

It discovers:

- Hosts
- Open Ports
- Running Services
- Operating Systems

---

## Common Uses

- Network Discovery
- Security Auditing
- Vulnerability Assessment
- Port Scanning

Example

Port 22 → SSH

Port 80 → HTTP

Port 443 → HTTPS
