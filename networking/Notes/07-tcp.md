# TCP (Transmission Control Protocol)

TCP is a reliable transport layer protocol.

It guarantees that data reaches the destination correctly.

---

## Features

### Connection Oriented

A connection is established before sending data.

Uses the Three-Way Handshake.

---

### Reliable

Lost packets are retransmitted.

---

### Full Duplex

Both devices can send and receive data simultaneously.

---

### Error Control

Checks whether data became corrupted during transmission.

---

### Flow Control

Controls the speed of data transfer so that the receiver is not overloaded.

---

### Congestion Control

Reduces network traffic when the network becomes busy.

---

## Real-Life Examples
