# HTTP & HTTPS

HTTP is used to transfer web pages.

Default Port:

80

---

HTTPS is the secure version of HTTP.

Uses SSL/TLS encryption.

Default Port:

443

---

# DHCP

Dynamic Host Configuration Protocol

DHCP automatically assigns:

- IP Address
- Subnet Mask
- Default Gateway
- DNS Server

Example:

When you connect your phone to Wi-Fi, DHCP automatically gives it an IP address.

---

# Ports

Ports identify which application should receive incoming data.

Examples

20 FTP

21 FTP Control

22 SSH

23 Telnet

25 SMTP

53 DNS

67 DHCP

68 DHCP

80 HTTP

110 POP3

143 IMAP

443 HTTPS

# VPN

VPN creates an encrypted tunnel between your device and the VPN server.

Benefits

- Encrypts Internet traffic
- Hides Public IP
- Improves privacy
- Access geo-restricted websites
