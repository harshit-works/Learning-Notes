# UDP (User Datagram Protocol)

UDP is a fast transport layer protocol.

Unlike TCP, it does not guarantee delivery.

---

## Features

- Connectionless
- No packet ordering
- Faster than TCP
- Less overhead
- Error checking is optional

---

## Uses

- Video Streaming
- Online Gaming
- VoIP
- DNS Queries

---

# TCP Three-Way Handshake

1. SYN

Client requests connection.

↓

2. SYN + ACK

Server accepts request.

↓

3. ACK

Client confirms.

Connection Established.

---

# ARP (Address Resolution Protocol)

ARP converts an IP Address into a MAC Address.

IP Address

↓

MAC Address

Used inside Local Area Networks (LAN).
