# Linux Permissions

View permissions

ls -l

Example

-rwxr-xr--

Permission Groups

Owner

Group

Others

Permission Types

r → Read

w → Write

x → Execute

---

## chmod

Changes file permissions.

Example

chmod 737 file.txt

Permission Numbers

7 = rwx

6 = rw-

5 = r-x

4 = r--

3 = -wx

2 = -w-

1 = --x

0 = ---
