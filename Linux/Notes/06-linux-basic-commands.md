# Linux Basic Commands

## ls -R

Shows files and subdirectories recursively.

---

## touch .filename

Creates a hidden file.

Example

touch .secret

---

## ls -a

Displays hidden files.

---

## ls -l

Displays detailed file information.

---

## clear

Clears the terminal screen.

---

## history

Shows previously executed commands.

---

## echo

Prints text.

Example

echo Hello

---

## printf

Prints formatted output.

---

## Linux is Case Sensitive

Example

notes.txt

and

Notes.txt

are different files.
