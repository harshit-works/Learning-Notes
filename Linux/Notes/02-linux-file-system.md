# Linux File System

Linux stores everything as files.

## Important Commands

### ls

Lists files and directories.

Example

ls

---

### pwd

Displays the current working directory.

Example

pwd

---

### cd

Changes directory.

Example

cd Documents

---

### cd ..

Moves one directory back.

---

### /

Represents the Root Directory.

Every directory starts from /.

---

### Tab

Auto-completes commands and filenames.

---

### mkdir

Creates a new directory.

Example

mkdir Projects

---

### touch

Creates an empty file.

Example

touch notes.txt

---

### mv

Moves or renames files.

Example

mv file.txt Documents/

---

### cp

Copies files.

Example

cp notes.txt backup.txt
