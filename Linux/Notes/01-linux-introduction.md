# Linux Introduction

## What is Linux?

Linux is an open-source operating system used in servers, cloud computing, cybersecurity, and embedded devices.

## Types of Interface

### GUI (Graphical User Interface)

- Uses windows, icons and mouse
- Beginner friendly

Examples:
- Windows
- Ubuntu Desktop

---

### CLI (Command Line Interface)

- Uses text commands
- Faster than GUI
- Preferred by system administrators and cybersecurity professionals

Example:

ls
pwd
mkdir
