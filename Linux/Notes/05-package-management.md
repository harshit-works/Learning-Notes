# Package Management

Ubuntu uses APT (Advanced Package Tool).

## sudo

Runs a command with administrator privileges.

Example

sudo apt update

---

## sudo su

Switches to the root user.

---

## apt

Package manager for Ubuntu.

Example

sudo apt install vim

---

## sudo apt update

Downloads the latest package list.

Does NOT install updates.

---

## sudo apt upgrade

Installs updates downloaded by apt update.
