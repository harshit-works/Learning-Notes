# AAA — Authentication, Authorization & Accounting

AAA is a security framework used to control and monitor access to systems and resources.

AAA stands for:

- Authentication
- Authorization
- Accounting

## 1. Authentication

Authentication answers:

> "Who are you?"

It verifies the identity of a user or device.

### Examples

- Username and password
- Fingerprint
- Face recognition
- Multi-factor authentication
- Security keys

---

## 2. Authorization

Authorization answers:

> "What are you allowed to do?"

After a user is authenticated, the system determines which resources and actions they are permitted to access.

### Example

An employee may be allowed to read company files but not delete them.

---

## 3. Accounting

Accounting answers:

> "What did you do?"

It records and monitors user activity.

### Examples

- Login time
- Logout time
- Files accessed
- Commands executed
- Changes made

Accounting is also commonly referred to as **auditing** or **accounting/logging**.


## Easy Way to Remember

**Authentication → Who are you?**

**Authorization → What can you access?**

**Accounting → What did you do?**
