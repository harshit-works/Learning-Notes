# CIA Triad

The CIA Triad is one of the fundamental concepts of cybersecurity.

CIA stands for:

- Confidentiality
- Integrity
- Availability

## 1. Confidentiality

Confidentiality means preventing unauthorized people from accessing information.

### Example

Only authorized employees should be able to access confidential company data.

### Common Security Measures

- Passwords
- Access controls
- Encryption
- Multi-factor authentication

---

## 2. Integrity

Integrity means keeping information accurate, complete, and protected from unauthorized modification.

### Example

A bank transaction should not be changed by an unauthorized person.

### Common Security Measures

- File integrity monitoring
- Hashing
- Digital signatures
- Access controls

---

## 3. Availability

Availability means that systems and information should be accessible when authorized users need them.

### Example

An online banking service should remain available to customers when they need to use it.

### Common Security Measures

- Backups
- Redundant systems
- Disaster recovery
- System monitoring
- Protection against denial-of-service attacks
