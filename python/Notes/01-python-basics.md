# Python Basics

## What is Python?

Python is a high-level, interpreted, and easy-to-read programming language. It is widely used in web development, automation, data science, artificial intelligence, and cybersecurity.

### Features

- Simple and readable syntax
- Cross-platform
- Open source
- Large community support
- Huge collection of libraries

---

# Variables

Variables are used to store data in memory.

Example:

```python
name = "Harshit"
age = 20
```

Rules for Variable Names:

- Can contain letters, numbers and underscore (_)
- Cannot start with a number
- Case-sensitive
- Avoid Python keywords

# Data Types

Python provides different built-in data types.

| Data Type | Example |
|-----------|---------|
| int | 25 |
| float | 3.14 |
| str | "Hello" |
| bool | True |
| list | [1,2,3] |
| tuple | (1,2,3) |
| set | {1,2,3} |
| dict | {"name":"Harshit"} |

# Input

The input() function accepts data from the user.

Example

```python
name = input("Enter your name: ")
```

---

# Output

The print() function displays output on the screen.

Example

```python
print("Hello")
```

---

# Type Conversion

Type conversion changes one data type into another.

Example

```python
age = int(input("Enter age: "))
```

Common Functions

- int()
- float()
- str()
